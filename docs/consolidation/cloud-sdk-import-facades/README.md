# Preserved cloud import facades

These 17 source-only forwarding files belonged to the cloud SDK baseline a9e47d9dd06e9eb413f87bc74d85e3924bb6eb78. The consolidated SDK already consumes the extracted engine repository and no longer has packages/game-engine. They are retained here byte-for-byte as migration evidence, outside active packages, so the obsolete monorepo facade tree does not become a second engine installation. Their targets and the WIP engine source are preserved separately. REDLINE production continues to use its accepted pinned runtime.
